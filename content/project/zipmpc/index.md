A method that imitates long-horizon MPC behaviour by learning a compressed, context-dependent cost function for a short-horizon MPC, achieving long-horizon performance at short-horizon computational cost.

- Project page: [zipmpc.github.io](https://zipmpc.github.io/)
- Paper: [ZipMPC: Compressed Context-Dependent MPC Cost via Imitation Learning](/publication/conference-paper-0/)
