A framework that replaces hand-tuned in-context prompt examples with task demonstrations, mapping language descriptions to control objectives via inverse optimal control to enable zero-shot generalization with built-in hallucination detection.

- Project page: [demonstrate-mpc.github.io](https://demonstrate-mpc.github.io/)
- Paper: [DEMONSTRATE: Zero-shot Language to Robotic Control via Multi-task Demonstration Learning](/publication/preprint/)
